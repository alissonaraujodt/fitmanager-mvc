# fitmanager-mvc
O FitManager é uma aplicação web feita em PHP para facilitar o dia a dia de academias, cuidando da gestão de alunos e do controle de acesso dos usuários. Ele foi construído usando o padrão MVC e PDO para garantir uma estrutura organizada e segura.

Tecnologias utilizadas:

-PHP 8+

-Arquitetura MVC (Model-View-Controller)

-Banco de dados MySQL com PDO e Prepared Statements

-Interface com HTML5, CSS3 e Bootstrap 5

-Versionamento via Git e GitHub

O que o sistema faz:

Autenticação de usuários: Login e logout com senhas criptografadas (password_hash e password_verify).

Níveis de acesso: Controle de permissões para perfis de administrador e operador.

Gestão de alunos: Cadastro, consulta, edição e remoção (CRUD completo).

Avisos e feedback: Mensagens dinâmicas para o usuário usando sessões do PHP.
